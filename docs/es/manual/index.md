# Manual de usuario de Revelado

*[Read in English](../../en/manual/index.md)*

Revelado funciona como un pequeño laboratorio de película en tu ordenador:

1. **[Instalación](instalacion.md)**: pon en marcha el motor y la app web desde el código.
2. **[Importar](importar.md)**: abre una carpeta; los RAW y JPG se emparejan por nombre.
3. **[Visor y máscaras](visor.md)**: mira las fotos al 100 %, con máscaras de ruido, aberración cromática y dominantes de color.
4. **[Selección](seleccion.md)**: elige y descarta a mano, o deja que la selección técnica (o Claude) proponga.
5. **[Cuarto oscuro](cuarto-oscuro.md)**: elige una película, revela **una muestra** y ajusta la receta.
6. **[Horno](horno.md)**: revela toda la selección, una foto cada vez, con el progreso en vivo.
7. **[Exportar](exportar.md)**: JPG o TIFF de 16 bits a la carpeta que elijas.

También en este manual:

- [Recetas y CLI](recetas-cli.md): cómo se guardan los ajustes y cómo automatizarlos;
- [Opciones de IA](ia.md): sin IA, con clave de API de Anthropic, o con tu propio Claude por MCP;
- [MCP](mcp.md): usar Revelado desde Claude Code o Claude Desktop;
- [Modo Rescate](rescate.md): próximamente.

**Tus originales nunca se modifican.** Revelado lee las carpetas de origen, nunca escribe en ellas y nunca sobrescribe una exportación.
