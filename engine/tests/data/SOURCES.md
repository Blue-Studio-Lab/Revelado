# Test data sources and attribution

The engine tests and `scripts/benchmark_quality.py` use a few real camera RAW files. They are **not stored in the
repository**: `python scripts/fetch_test_raws.py` downloads them into `test-data/` (gitignored) and verifies each one
against the sha256 pinned in [`test_raws.json`](test_raws.json).

All files come from **[raw.pixls.us](https://raw.pixls.us)**, the community archive of camera RAW samples run by
the PIXLS.US community, and every file listed here is published there under the
**Creative Commons Zero 1.0 Universal (CC0-1.0)** public-domain dedication. The licence of each file was checked on
the archive's repository listing on 2026-11-17 (`--check-licence` re-checks it). CC0 needs no attribution; we credit
the archive and its contributors anyway, with thanks.

Roles: `sony_33mp` is the 33 MP reference for timings and memory; `high_iso` and `high_iso_cr3` are the noisy files
for noise-reduction demos and benchmarks; `canon`, `nikon`, `fuji` cover the other major RAW formats (CR2, NEF,
X-Trans RAF). `raw_only_folder` in the tests copies the Canon file alone into a temp folder.

Synthetic fixtures (JPG-only folders, test scenes) are generated by the tests themselves. No client photograph
and no private file is used anywhere in the public test suite (the optional private golden test reads the
maintainer's own files from a local folder given by an environment variable, outside the repository).
